# Proyecto Triple Espresso

## Descripción del proyecto

**Triple Espresso** es una página web para una cafetería y zona de estudio ubicada en Triple Peaks.

El proyecto presenta información sobre la cafetería, incluyendo su horario de atención y ubicación, además de enlaces de navegación, una sección para reservar una mesa y un pie de página con enlaces a redes sociales.

La página también incorpora un formulario de reserva en el que los usuarios pueden ingresar su nombre, número de comensales, fecha y hora, y correo electrónico. Los campos del formulario son obligatorios y se utilizan diferentes tipos de entrada HTML según la información solicitada.

Además, se implementaron estados `hover` para proporcionar interactividad a los elementos clicables.

## Tecnologías y técnicas utilizadas

- **HTML5**
  - Estructura semántica de la página.
  - Uso de elementos como `header`, `nav`, `section`, `form`, `fieldset`, `label`, `input`, `button` y `footer`.
  - Enlaces internos mediante atributos `href` e identificadores `id`.
  - Uso de diferentes tipos de campos de formulario: `text`, `number`, `datetime-local`, `email` y `checkbox`.

- **CSS3**
  - Creación y aplicación de estilos visuales.
  - Uso de `Flexbox` para la alineación y distribución de elementos.
  - Uso de `position` y `z-index` para controlar la posición y el orden de apilamiento de algunos elementos.
  - Uso de `background-image`, `background-size: cover` y `background-position` para las imágenes de fondo.
  - Uso de `border-radius` para bordes redondeados y elementos circulares.
  - Uso de `box-sizing: border-box` para controlar las dimensiones de los campos del formulario.
  - Diseño adaptable mediante unidades relativas y `width: 100%`.
  - Implementación de estados `:hover` y transiciones para proporcionar retroalimentación visual al usuario.

- **Tipografías**
  - Uso de las familias tipográficas `Inter` y `Noto Serif`.
  - Definición de tamaños, pesos, estilos y alturas de línea según las especificaciones del diseño.

- **Accesibilidad y semántica**
  - Uso de elementos HTML semánticos.
  - Asociación de etiquetas `label` con los campos correspondientes.
  - Uso de textos alternativos y estructura adecuada de los elementos.
